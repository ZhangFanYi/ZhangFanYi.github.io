五、代码修改/补丁 (适配阶段)
================================================================================

  [Patch 1] base_dataset.py — 视频后端修复
    文件: lingbotvla/data/vla_data/base_dataset.py
    修改: video_backend 参数从默认 "torchcodec" 改为 "pyav"
    原因: DCU 容器未安装 torchcodec，使用 pyav 解码
    对应 MD: 是 (MD 要求安装 pyserial + deepdiff + 升级 lerobot)

  [Patch 2] flex_attention.py (项目层) — compile 开关
    文件: lingbotvla/models/vla/pi0/flex_attention.py
    修改: 添加 LINGBOT_DISABLE_FLEX_COMPILE 环境变量控制
          默认启用 torch.compile(flex_attention, mode="max-autotune-no-cudagraphs")
    备份: .bak
    对应 MD: 否 (MD 要求 use_compile: false，我们额外在模型代码层启用)

  [Patch 3] flex_attention.py (inductor 层) — block_m AttributeError 修复
    文件: /usr/local/lib/python3.10/dist-packages/torch/_inductor/kernel/flex/flex_attention.py
    修改: 两处 else 分支，conf.block_m → getattr(conf, "block_m", getattr(conf, "block_m1", 0))
    原因: ROCmFlexBwDConfig 没有 block_m 属性，autotune 模式下会 crash
    备份: .bak2
    对应 MD: 否 (MD 未提及此 bug，因 MD 基于 torch 2.7.1)

  [Patch 4] config.json — 删除 dtype 字段
    文件: /workspace/models/lingbot-vla-4b-posttrain-robotwin/config.json
    修改: 删除 "dtype": "bfloat16" 字段
    原因: Qwen2.5-VL 代码不识别 dtype 字段会报错
    对应 MD: 是 (MD 明确要求)

  [Patch 5] pyserial 安装
    修改: pip install pyserial==3.5
    原因: serial_win32.py 导入 serial 模块
    对应 MD: 否 (MD 未提及，代码隐式依赖)

  [Patch 6] deepdiff 安装
    修改: pip install deepdiff==9.1.0
    原因: 代码导入 deepdiff
    对应 MD: 否 (MD 未提及，代码隐式依赖)

  [Patch 7] lerobot 升级
    修改: pip install -U lerobot (0.3.3 → 0.4.2)
    原因: MD 要求
    对应 MD: 是


六、环境变量配置
================================================================================

  训练启动时需要的环境变量:

    HF_ENDPOINT=https://hf-mirror.com          # HF 镜像
    QWEN25_PATH=/workspace/models/Qwen2.5-VL-3B-Instruct
    HIP_VISIBLE_DEVICES=0,1,2,3,4,5,6,7        # 全部 8 卡
    CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7       # 训练脚本需要此变量计算 nproc
    PYTORCH_HIP_ALLOC_CONF=expandable_segments:True
    TOKENIZERS_PARALLELISM=false
    TRITON_FLEX_TUNED=1                         # 启用 asymmetric bwd 配置
    TRITON_FLEX_ASYMMETRIC_BWD=1                # 同上 (旧名兼容)
    TORCHINDUCTOR_FORCE_POINTER_RANGE=1
    HSA_FORCE_FINE_GRAIN_PCIE=1

  对照 MD:
    MD 有:  HF_ENDPOINT, QWEN25_PATH, HIP/CUDA_VISIBLE_DEVICES, PYTORCH_HIP_ALLOC_CONF
    MD 无:  TRITON_FLEX_TUNED, TRITON_FLEX_ASYMMETRIC_BWD, TORCHINDUCTOR_FORCE_POINTER_RANGE,
            HSA_FORCE_FINE_GRAIN_PCIE
    以上 4 个是本次优化新增的。


七、性能基准测试结果
================================================================================

  测试配置: pusht.yaml (micro_batch_size=8, global_batch=64, 8 GPU)
  编译模式: torch.compile(flex_attention, mode="max-autotune-no-cudagraphs")

  首次运行 (含编译 warmup):
    Step 1:   ~120s (autotune 编译 24 个配置/kernel shape)
    Step 2-3: ~1.7-1.8s (编译后稳定)

  120 步完整运行统计 (最后 110 步, warmup=10):
    Mean StepTime:    2.093s
    Median StepTime:  1.838s
    P50:              1.838s
    P90:              2.646s
    P95:              3.189s
    Min:              1.797s
    Max:              3.571s (checkpoint 保存 spike)

  吞吐量:
    samples/s total:  30.58 (global_batch=64)
    samples/s/gpu:    3.82

  纯训练性能 (排除 >3s spike):
    Mean:             2.006s
    Median:           1.842s
    samples/s total:  31.90
    samples/s/gpu:    3.99

  对比:
    MD 文档基准 (8 GPU mb8): 30.96 samples/s → 我们 30.58 (基本持平)
    禁用 compile 时 (4 GPU mb1): ~3.6s/step → 启用后 ~1.8s/step (提速 ~50%)

十、已知问题与注意事项
================================================================================

  1. 容器 overlay 100% 满 (3.5T):
     - 无法 pip install 或写入新文件
     - 新文件用 /zhangyifan/ (NFS) + 符号链接解决
     - 可清理: triton (3.5G), aiter (2.8G), mooncake (583M), lightop (484M)

  2. PYTORCH_HIP_ALLOC_CONF 已弃用:
     - DTK 2.9.0 提示: use PYTORCH_ALLOC_CONF instead
     - 功能不受影响，可忽略

  3. 首次编译开销:
     - torch.compile 首次运行需 ~2 分钟 autotune
     - 24 个配置/kernel shape 编译
     - 后续 step 缓存复用，无额外开销

  4. Checkpoint 保存 spike:
     - 每 20 步左右有一次 ~3s 的 spike (checkpoint 保存)
     - 正常现象，不影响稳态性能

  5. inductor 补丁是改 torch 包内部:
     - pip upgrade 会覆盖
     - 当前容器不会升级 torch，风险可控
     - 如需升级，需重新打 Patch 3

  6. 运行推理服务:
     docker exec -d fzx_lingbot bash -lc '
     cd /workspace/lingbot-vla
     export HF_ENDPOINT=https://hf-mirror.com
     export QWEN25_PATH=/workspace/models/Qwen2.5-VL-3B-Instruct
     export HIP_VISIBLE_DEVICES=0
     python -m deploy.lingbot_vla_policy \
       --model_path /workspace/models/lingbot-vla-4b-posttrain-robotwin \
       --use_length 50 --port 8006'
